4.
Hvilke av ligningene nedenfor er feiltypet? For de som er riktig typet, 
hva kan du si om typen til xs, og hvilke av dem holder?

[] : xs = xs
[] : xs = [[],xs]
xs : [] = xs
xs : [] = [xs]
xs : xs = [xs,xs]
xs : [xs] = [xs,xs]
[[]] ++ xs = xs
[[]] ++ xs = [xs]
[[]] ++ xs = [[],xs]
[[]] ++ [xs] = [[],xs]
[xs] ++ [] = [xs]
[xs] ++ [xs] = [xs,xs]
