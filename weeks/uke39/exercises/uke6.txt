4. Typen av ikke-tomme lister med elementer av type a kunne defineres ved
	data List a = Wrap a | Cons a (List a)

`foldr` er naturlig fold for lister, slik at `foldr (:) []` er identitet på lister, dvs. foldr (:) [] xs == xs, for envher liste xs::[a]. En tilsvarende egenskap for  
	foldL :: ... -> ... -> Pist a -> b 
blir at `foldL Wrap Cons` er identiteten på `List a`, dvs. foldL Wrap Cons ls == ls, for enhver ls::List a.

4.a. Definer foldL slik at denne egenskapen holder.

4.b. Bruk foldL (og evt. andre fold) for å definere funksjoner
	clist :: [a] -> List a
	list :: List a -> [a]
s.a., f.eks.:
	ghci> clist [1, 2, 3]
	Cons 1 (Cons 2 (Wrap 3))
og	ghci> list (Cons 1 (Cons 2 (Wrap 3)))
	[1, 2, 3]
